Getting started

Inkflit lives in the menu bar. Call it up with one shortcut, jot something down, and it gets out of the way. Notes save themselves as you type.

  1. Show the window with the global shortcut, ⌃⌥Space by default (you can change it in Settings → General), or click the menu bar icon and choose Open Inkflit.
  2. Write. Changes are saved automatically; there is no Save button.
  3. Hide it with the same shortcut or Esc (by default, twice within 0.6 seconds in Vim Normal mode). Switching to another app also hides it.

Where the window appears

The window opens on the display under the pointer, on the Space you are using now, so it never pulls you back to another desktop. It keeps the position you gave it, also after a restart.

Drag the toolbar's empty middle to move the window, and drag an edge to resize it. Restore the default size under Settings → Appearance → Window size → Reset.

Guide notes

  • The first launch creates seven guide notes in your language. Edit or delete them freely.
  • Restore Guide Notes at the bottom of Settings adds a fresh set at the front and opens the welcome note.

Notes

Notes are kept in order like the pages of a notebook: the first note is the oldest, and a new note is added at the end. The toolbar shows where you are, for example 2 / 5.

  • New note: ⌘N or the + button.
  • Turn pages: ⌘[ and ⌘], or the arrows in the toolbar. ⌘⇧[ and ⌘⇧] jump to the first and the last note.
  • Jump to a page: ⌘1 to ⌘9 open notes 1 to 9.

The footer shows when the current note was created, in your local time. Notes created before this was recorded show no date.

Deleting and undoing

⌘D deletes the current note right away. A notice stays for 12 seconds; press ⌘U or click it to bring the note back.

Deleted notes are never erased. They stay in the Trash folder, and Settings → Backups → Restore deleted note… brings any of them back as a new note.

Search and commands

Two panels share the same keys: type to filter, ↑ ↓ to choose, Return to open, Esc to close.

Search notes ⌘⇧F

  • Searches the text of all current notes, one match per note.
  • With an empty field it lists every note, so it works as a table of contents.
  • Backups and the Trash are not searched.

Command palette ⌘⇧P

Runs note actions and changes settings without opening the Settings window.

Search for format and select Format Note to tidy expression spacing in math blocks and format JavaScript, TypeScript, JSON, HTML, CSS, Markdown, and YAML code blocks in the current note. Code uses your Code indentation setting. The whole operation can be undone in one step.

  • Commands marked › open a second list, such as accent colors or languages. The current value has a ✓.
  • For opacity, blur and backups you can also type a number, for example 75.
  • Esc, or ⌫ in an empty field, goes back one level with the previous row still selected.
  • Typing on the first level also finds second-level options, so english finds Language: English.

Press either shortcut again to close its panel, or the other shortcut to switch panels.

Writing

Notes are plain Markdown. Headings, lists, emphasis and links are styled as you type, and the source stays readable in any editor.

  • Checkboxes: - [ ] and - [x] can be clicked to tick them off.
  • Comments: a line starting with // is a comment. ⌘/ toggles it for the current or selected lines.
  • Code fences: ```js fences are highlighted by language.

While you move through a long note, three lines stay visible above and below the cursor.

Snippets

Type @ and a word to insert a value.

  • Return inserts the first format, ↑ ↓ pick another, Esc closes the list.
  • A word with several formats lists them all: @date lists every date format.
  • Part of a word, or letters in order, also work: @wk finds @week.
  • @ alone lists one row per word.
  • The preview is exactly what will be inserted; clock values stay up to date.

Your own snippets

Add your own in Settings → Snippets or with Manage snippets in the command palette. They are saved in snippets.json in the notes folder, so they move and back up with your notes.

Use Snippet availability in Settings → Snippets to turn groups or individual built-in snippets on and off. Toggle Custom snippets there to hide all your own snippets, or uncheck Enabled beside a single row. Disabled snippets are hidden from suggestions and the placeholder picker. Placeholders already in a template still expand.

  • One trigger, several rows: like macOS text replacements. Put a few addresses under addr; @addr lists them all and inserts the first by default.
  • Same name as a built-in word: your row comes first, so your own date becomes the default.
  • Content can span lines.

Caret stops

Dear {cursor:name},
{cursor}
{date}
  1. After inserting, “name” is selected; type to replace it.
  2. Press Tab to go to the empty line.
  3. Press ⇧Tab to go back to the name; what you typed is selected again.
  • Marked: the stop you are filling has a strong tint and a solid underline; the others a light tint and a dotted underline, and an empty one is a thin bar. Changed or not, until the stops end.
  • Tab is for stops: while they are active, Tab and ⇧Tab only move between stops, also in a checklist.
  • Ending: reach the last stop, move the caret out of them, or press Esc. Then Tab indents again.
  • That Esc does not hide the window; in Vim mode it also returns to Normal mode.
  • Last stop not at the end: one more Tab lands at the end of the snippet.

Good to know

  • Later lines of a multi-line snippet follow the indentation of the line it goes on.
  • A snippet with stops inserted inside another one’s stop ends the outer stops.
  • A snippet whose value takes a moment (an IP address): if you move the caret meanwhile, it is not pulled back.

Feature blocks

A block turns part of a note into a small tool: a checklist, a calculator, a running total or a code snippet. A note can hold any number of blocks.

Adding and changing blocks

  1. On an empty line, type /. (In Vim mode, enter insert mode first.)
  2. Pick a block with the arrow keys and Return, or click it.
  3. Press Return on the last line to add a line inside the block.
  • Block header or ⌘K: change the type, turn it back into plain text, or delete it.
  • ⌘⇧D: delete the current block.
  • ⌘O / ⌘⇧O: add an empty line below / above the current line or block.

All of these can be undone.

Math

A math block is scratch paper that calculates: one expression per line, end it with =, and the result appears after it. Define variables, call functions, and convert units and currencies.

Start a math block

  • Block: on an empty line type / and choose Math. The block starts with :::inkflit math and ends with :::end.
  • Whole note: make the first line just math, optionally with a title such as math: Trip budget.
    • Everything to the end of the note is calculated; there is no end marker.
    • Other blocks and code fences in the note are left out.
    • To calculate only part of a note, use a block or ```math.
  • Markdown fence: start with ```math and end with ```.
math: Trip budget
flights: 2400
hotel: 380 * 4
flights + hotel =
ans / 2 =
// split between two

Inkflit treats months and years as fixed durations when converting units. It does not count calendar days between dates.

You can write the full names minute and second in formulas. 1 minute to s = gives 60 s, and 1 second to ms = gives 1000 ms. In the snippet picker, type @sec and choose @second to insert s. In a formula, write s or second. Inkflit does not recognize sec as a time unit.

Currency

  • Write: 10 USD to EUR =. in works in place of to.
  • Codes: three uppercase letters. Lowercase usd is not a currency.
  • One amount per line: 10 USD + 5 EUR and price USD to EUR do not work.

Rates

  • Source: European Central Bank reference rates from Frankfurter, updated once each working day.
  • Date: results carry the rate date, such as 8.62 EUR · 2026-11-18.
  • Download: while a math block is open, at most once an hour; about 100 seconds after a failure.
  • Messages: before rates arrive the line shows “Exchange rates loading or unavailable”; a code missing from the table shows “Unsupported currency”.

Limits

  • An expression is at most 256 characters.
  • No modulo, matrices, strings, comparisons, custom functions, or assignment with = inside an expression.

Code

  • Whole-note code: make the first line code js to highlight and edit the whole note as that language. ⌘L changes the language on the first line.
  • ⌘L chooses the language of the current code block.
  • Brackets and quotes are closed for you. Return keeps the indentation, Tab indents and ⇧Tab outdents.
  • With nothing selected, ⌘C copies the whole block.

Indentation (2 spaces, 4 spaces or tabs) and the three color themes are in Settings → Edit, with a live preview.

Vim mode

Vim keys are on by default. The editor starts in Normal mode. Press i to type and Esc to go back. In Normal mode, press Esc twice within 0.6 seconds by default. Turn off Double Esc to hide in Editing settings to hide with one press.

  • In normal mode Inkflit switches to an ASCII keyboard layout so commands work, and restores your input method when you start typing or leave the window.
  • An open input method candidate is cancelled before Esc leaves insert mode.
  • Undo history is kept per note until you quit.

This is Vim emulation in the editor, not Neovim, so a vimrc is not loaded.

Turn it off in Settings → Edit → Vim Mode or from the command palette. Then you type directly, Esc hides the window, and ⌘Z / ⌘⇧Z undo and redo.

Your data

Everything stays on your Mac. Each note is a UTF-8 Markdown file:

~/Documents/Inkflit/
  notes/       one .md file per note
  index.json   order and the selected note
  backups/     previous versions
  trash/       deleted notes

Saving

  • Saves half a second after you stop typing, and at least every two seconds while you type.
  • Switching notes, hiding the window or quitting saves at once.
  • If a save fails, the footer says so, and Inkflit will not quit until a save succeeds.

Backups and recovery

  • While you edit, the previous version of a note is kept at most once every five minutes. Choose how many to keep in Settings → Backups.
  • Restore a previous version… and Restore deleted note… create a new note and leave the original file in place.
  • If index.json is damaged, Rebuild index… recreates it from the note files. The old index is kept.

Choosing another folder copies the whole store there and keeps the original.

Inkflit has no cloud sync. Include the notes folder in your own backups, or choose a folder that your sync service already covers.

Automation

Other apps and AI agents can read and edit notes through a local MCP server or inkflit:// links. Both go through the running app, so saving and backups work as usual.

MCP

Add Inkflit to your MCP client, then restart the client:

# Codex
codex mcp add inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# Claude Code
claude mcp add --transport stdio --scope user inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# Other clients
{"mcpServers":{"inkflit":{"command":"/Applications/Inkflit.app/Contents/MacOS/Inkflit","args":["--mcp"]}}}

Tools: list_notes, search_notes, get_note, get_current_note, analyze_note, preview_note_format, apply_note_format, create_note, append_note, replace_note, delete_note.

Use limit, cursor, and include_content: false with list_notes to get pages of short summaries. get_current_note reads the selected note. analyze_note returns calculation and checklist results for an id or index.

Call preview_note_format with the note id to review the diff. Pass the same id and the returned preview_id to apply_note_format. If the note has changed, request a new preview.

  • Pick a note by index (the number shown in Inkflit) or by its stable id. Indices shift when notes are added or deleted.
  • New notes go to the end. Pass position as "first", "last" or a number to place them elsewhere.
  • Deleted notes go to the Trash.

Links

open 'inkflit://note/append?index=2&content=Remember%20milk'
open 'inkflit://note/search?query=milk'
open 'inkflit://note/get?index=1'

Actions are list, get, search, create, append, replace and delete. Add x-success and x-error callback URLs to receive the result as JSON.

Use inkflit://note/open?index=2 to open a note, or inkflit://settings/appearance and inkflit://settings/snippets to open settings.

Links that write or delete run immediately. Only open links you trust.

Troubleshooting

The shortcut does nothing

Another app may already use it. The menu bar shows Settings… (shortcut unavailable) in that case; choose a different shortcut in Settings → General.

Launch at login stays off

macOS may need your approval. Allow Inkflit in System Settings → General → Login Items.

Notes changed outside Inkflit

If the note files were edited by another app while Inkflit was running, Inkflit refuses to overwrite them. Copy your current text somewhere safe and restart Inkflit.
