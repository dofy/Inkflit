开始使用

Inkflit 常驻在菜单栏。按一个快捷键就能叫出来，记完随手收起。输入时自动保存。

  1. 打开窗口：按全局快捷键，默认是 ⌃⌥Space（可在“设置 → 通用”中更改），或点菜单栏图标，选择“打开 Inkflit”。
  2. 开始写：内容会自动保存，没有保存按钮。
  3. 收起窗口：再按一次快捷键，或按 Esc。切换到其他应用时也会自动收起。

窗口出现在哪里

窗口会出现在鼠标所在的显示器、你当前所在的桌面上，不会把你拉回别的桌面。窗口位置会被记住，重启后也一样。

拖动工具栏中间的空白处可以移动窗口，拖动边缘可以调整大小。

引导笔记

  • 第一次启动时，Inkflit 按你的语言创建七篇引导笔记，可以随意修改或删除。
  • 设置窗口底部的“重新生成引导笔记”：在最前面放一套新的引导，并打开欢迎页。

笔记

笔记像本子的书页一样排列：第一篇是最早写的，新建的笔记加在最后。工具栏会显示当前位置，比如 2 / 5。

  • 新建：⌘N，或工具栏上的 +。
  • 翻页：⌘[ 和 ⌘]，或工具栏上的箭头。⌘⇧[ 和 ⌘⇧] 跳到第一条和最后一条笔记。
  • 跳到某一页：⌘1 到 ⌘9 打开第 1 到第 9 篇。

底栏显示当前笔记的创建时间（本地时间）。在记录创建时间之前就有的笔记不显示日期。

删除与撤销

⌘D 直接删除当前笔记。提示会保留 12 秒，按 ⌘U 或点击提示就能找回。

删除的笔记不会被真正抹掉，而是放进回收站文件夹。在“设置 → 备份 → 恢复已删除笔记…”中可以把任意一篇恢复成新笔记。

搜索与命令

两个面板的按键一样：输入文字筛选，↑ ↓ 选择，Return 打开，Esc 关闭。

搜索笔记 ⌘⇧F

  • 在所有当前笔记的正文里查找，每篇笔记列一条结果。
  • 输入框为空时列出全部笔记，可以当目录用。
  • 不搜索备份和回收站。

命令面板 ⌘⇧P

不用打开设置窗口，就能执行笔记操作、修改设置。

  • 带 › 的命令会打开第二级列表，比如界面主色、语言。当前生效的选项带 ✓。
  • 不透明度、模糊和自动备份可以直接输入数字，比如 75。
  • 按 Esc，或在空输入框里按 ⌫，返回上一级，之前选中的那一项仍然选中。
  • 在第一级直接输入，也能搜到第二级的选项，比如输入 english 会出现“语言：English”。

再按一次同一个快捷键关闭面板；按另一个快捷键则切换到另一个面板。

书写

笔记就是普通的 Markdown。标题、列表、强调和链接会边写边显示样式，源文件用任何编辑器打开都清楚易读。

  • 复选框：- [ ] 和 - [x] 可以直接点击勾选。
  • 注释：以 // 开头的行是注释。⌘/ 为当前行或选中的行添加或取消注释。
  • 代码围栏：```js 这样的代码围栏会按语言高亮。

在长笔记里移动光标时，光标上下始终保留三行可见。

片段

输入 @ 加一个词，插入常用值。

  • Return 插入第一种格式，↑ ↓ 选其他格式，Esc 关闭列表。
  • 一个词有多种格式时全部列出：@date 列出所有日期格式。
  • 只打一部分，或按顺序打几个字母也能找到：@wk 找到 @week。
  • 只输入 @：每个词显示一行。
  • 预览就是要插入的内容，时间类的值实时更新。

@now日期和时间（@datetime）、带秒（@datetimesec）、ISO 8601（@iso）、长格式

  • 在代码里、或紧跟在字母后面时不弹出，所以邮箱地址不受影响。

自定义片段

在“设置 → 片段”或命令面板的“管理片段”中添加。保存在笔记文件夹里的 snippets.json，随笔记一起迁移和备份。

  • 一个触发词可以有几行：像 macOS 的文字替换。几个地址都用 addr，@addr 会全部列出，默认插入第一行。
  • 和内置词同名：你的行排在前面，所以自己写的 date 会成为默认格式。
  • 内容可以多行。

光标位置

您好 {cursor:姓名}：
{cursor}
{date}
  1. 插入后“姓名”被选中，直接输入就能替换。
  2. 按 Tab 跳到空行。
  3. 按 ⇧Tab 回到“姓名”，填过的内容会再次被选中。
  • 标记：正在填的位置是深色底纹加实线下划线；其他位置是浅色底纹加点状下划线，空位置是一条竖线。改没改过都一样，直到跳转结束。
  • Tab 只管跳转：跳转期间 Tab 和 ⇧Tab 只用来跳转，清单里也一样。
  • 结束跳转：到达最后一个位置、把光标移出这些位置、或按 Esc。之后 Tab 恢复缩进。
  • 这次 Esc 不收起窗口；Vim 模式下同时回到普通模式。
  • 最后一个位置不在末尾时，再按一次 Tab 跳到片段末尾。

注意

  • 多行片段从第二行起跟随当前行的缩进。
  • 在一个位置里再插入带光标位置的片段，外层剩下的位置会失效。
  • 值要等一会儿才拿到的片段（比如 IP）：如果期间光标移走了，插入时不会把光标拉回来。

功能块

功能块把笔记的一部分变成小工具：清单、计算器、合计或一段代码。一篇笔记里可以放任意多个功能块。

插入和修改功能块

  1. 在空行输入 /。（Vim 模式下请先进入插入模式。）
  2. 用方向键和 Return 选择，或直接点击。
  3. 要离开功能块，在块的最后一个空行再按一次 Return。
  • 块的标题栏或 ⌘K：更改类型、转回普通文本或删除。
  • ⌘⇧D：删除当前块。
  • ⌘O / ⌘⇧O：在当前行或块的下方 / 上方插入空行。

这些操作都可以撤销。

功能块类型

功能块作用
清单每行一个复选框。点击勾选，或在行尾输入 /x。Tab 和 ⇧Tab 缩进和取消缩进，子项会跟着父项一起移动。
计算在行尾输入 = 得出结果，支持变量、函数、单位和货币，见计算。
求和 / 平均值对块里的数字求和或求平均，不计算表达式。
只算独立的数字：1.2.3.4、IP、日期 2026-11-19、时间 14:05 不算；行首的编号 1.、1.2. 也不算。
计数统计项目数、词数和字符数。
代码按语言高亮代码，见代码。

以 // 开头的行不参与合计和计数。

整篇笔记

第一行只写一个关键词，整篇笔记就是这种类型，没有结束标记。生效时关键词会以强调色标出。

计算

计算块是随手可算的草稿纸：一行一个式子，行尾写 =，结果就显示在后面。可以定义变量、调用函数、换算单位和货币。

创建计算块

  • 功能块：在空行输入 /，选择“计算”。块以 :::inkflit math 开头，以 :::end 结尾。

    • 一直算到笔记末尾，没有结束标记。
    • 笔记里的其他功能块和代码块不参与计算。

  • 写法：10 USD to CNY =。to 也可以写成 in。

  • 一行一笔：10 USD + 5 EUR、price USD to CNY 都不行。

汇率

  • 来源：Frankfurter 提供的欧洲央行参考汇率，工作日每天更新一次。
  • 日期：结果后面带汇率日期，比如 66.67 CNY · 2026-11-18。
  • 下载：打开计算块时下载，最多每小时一次；失败后约 100 秒重试。

用 @ 插入函数、单位和货币

在计算块里输入 @，除了日期等普通片段，还会多出三个词。它们只在计算块里出现。

词内容
@fn全部函数，旁边是说明。插入 sqrt() 后光标停在括号里，写完参数按 Tab 跳到括号后面。
@unit上表中的单位，旁边是类别。
@cur全部货币，显示名称和对本地货币的汇率：简体中文对 CNY，繁体中文对 HKD，日语对 JPY，英语对 USD。
  • 名字可以单独用：@sqrt、@km、@kilometer、@usd 直接找到那一项。
  • 数字后面可以紧接 @：10@km。
  • 和已有片段重名时让给已有片段：分钟用 @minute（@min 是函数），毫秒用 @millisecond（@ms 是时间戳）。

限制

  • 一个式子最长 256 个字符。
  • 不支持取余、矩阵、字符串、比较、自定义函数，也不能在式子里用 = 赋值。

代码

  • 整篇代码笔记：第一行写 code js，整篇按这种语言高亮和编辑。⌘L 改的是第一行的语言。
  • ⌘L 选择当前代码块的语言。
  • 括号和引号会自动补全。Return 保持缩进，Tab 缩进，⇧Tab 取消缩进。
  • 没有选中内容时，⌘C 复制整个代码块。

缩进方式（2 个空格、4 个空格或 Tab）和三种配色在“设置 → 编辑”中，可以实时预览。

Vim 模式

Vim 按键默认开启。编辑器先处于普通模式，按 i 开始输入，按 Esc 回到普通模式。在普通模式下按 Esc 会收起窗口。

  • 普通模式下，Inkflit 会临时切换到英文（ASCII）输入法，让命令键直接生效；开始输入或离开窗口时恢复你原来的输入法。
  • 如果输入法候选框还开着，按 Esc 会先取消候选，再退出插入模式。
  • 每篇笔记的撤销记录会保留到退出应用为止。

这是编辑器里的 Vim 模拟，不是 Neovim，不会读取 vimrc。

在“设置 → 编辑 → Vim 模式”或命令面板里可以关闭。关闭后直接输入，Esc 收起窗口，⌘Z / ⌘⇧Z 撤销和重做。

数据

所有内容都只保存在你的 Mac 上。每篇笔记是一个 UTF-8 编码的 Markdown 文件：

~/Documents/Inkflit/
  notes/       每篇笔记一个 .md 文件
  index.json   笔记顺序和当前选中的笔记
  backups/     历史版本
  trash/       已删除的笔记

保存

  • 停止输入半秒后保存；连续输入时至少每两秒保存一次。
  • 切换笔记、收起窗口、退出应用时立即保存。
  • 保存失败时底栏会提示；保存成功之前无法退出应用。

备份与恢复

  • 编辑时，每篇笔记最多每五分钟保留一个旧版本。保留多少个可以在“设置 → 备份”中选择。
  • “恢复历史版本…”和“恢复已删除笔记…”都会新建一篇笔记，原文件保留不动。
  • 如果 index.json 损坏，“重建索引…”会根据笔记文件重新生成索引，旧索引会保留。

更改保存位置时，会把整个存储目录复制过去，原目录保留不动。

Inkflit 没有云同步。请把笔记文件夹纳入你自己的备份，或者选择一个同步服务已经覆盖的文件夹。

自动化

其他应用和 AI 助手可以通过本机 MCP 服务或 inkflit:// 链接读写笔记。两种方式都经过正在运行的 Inkflit，保存和备份照常进行。

MCP

把 Inkflit 加进你的 MCP 客户端，然后重启客户端：

# Codex
codex mcp add inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# Claude Code
claude mcp add --transport stdio --scope user inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# 其他客户端
{"mcpServers":{"inkflit":{"command":"/Applications/Inkflit.app/Contents/MacOS/Inkflit","args":["--mcp"]}}}

工具：list_notes、search_notes、get_note、create_note、append_note、replace_note、delete_note。

  • 用 index（Inkflit 里显示的序号）或稳定的 id 指定笔记。增删笔记后序号会变化。
  • 新笔记默认加在最后。position 可以设为 "first"、"last" 或一个数字，放到其他位置。
  • 删除的笔记进入回收站。

链接

open 'inkflit://note/append?index=2&content=Remember%20milk'
open 'inkflit://note/search?query=milk'
open 'inkflit://note/get?index=1'

可用的操作有 list、get、search、create、append、replace 和 delete。加上 x-success 和 x-error 回调地址，可以收到 JSON 格式的结果。

写入和删除类的链接会立即执行，只打开你信任的链接。

常见问题

按快捷键没有反应

可能有其他应用占用了这个快捷键。这时菜单栏里会显示“设置…（快捷键不可用）”，请在“设置 → 通用”中换一个快捷键。

开机启动打不开

macOS 可能需要你授权。请在“系统设置 → 通用 → 登录项”中允许 Inkflit。

笔记在 Inkflit 之外被修改

如果 Inkflit 运行时笔记文件被其他应用改过，Inkflit 会拒绝覆盖这些文件。请先把当前内容复制到安全的地方，然后重启 Inkflit。
