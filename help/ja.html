はじめに

Inkflit はメニューバーに常駐します。ショートカットひとつで呼び出し、書き終えたらすぐにしまえます。入力内容は自動で保存されます。

  1. ウインドウを表示：グローバルショートカット（初期設定は ⌃⌥Space。「設定 → 一般」で変更できます）を押すか、メニューバーのアイコンから「Inkflit を開く」を選びます。
  2. 書く：変更は自動で保存されます。保存ボタンはありません。
  3. 隠す：同じショートカットか Esc を押します。ほかのアプリに切り替えたときも自動で隠れます。

ウインドウの表示場所

ウインドウはポインタがあるディスプレイの、いま使っているデスクトップに表示されます。別のデスクトップに引き戻されることはありません。位置は記憶され、再起動後も保たれます。

ツールバー中央の空いている部分をドラッグすると移動、端をドラッグするとサイズを変更できます。

ガイドノート

  • 初回起動時に、使用中の言語で 7 つのガイドノートが作成されます。自由に編集・削除できます。
  • 設定ウインドウ下部の「ガイドノートを再作成」：新しいガイドを先頭に追加し、ようこそページを開きます。

ノート

ノートはノートブックのページのように並びます。最初のノートがいちばん古く、新しいノートは末尾に追加されます。ツールバーには現在の位置が表示されます（例：2 / 5）。

  • 新規作成：⌘N、またはツールバーの +。
  • ページをめくる：⌘[ と ⌘]、またはツールバーの矢印。⌘⇧[ と ⌘⇧] で最初と最後のノートへ移動します。
  • ページへ移動：⌘1〜⌘9 で 1〜9 番目のノートを開きます。

フッターには現在のノートの作成日時（ローカル時刻）が表示されます。作成日時の記録が始まる前からあるノートには表示されません。

削除と取り消し

⌘D で現在のノートをすぐに削除します。通知が 12 秒間表示され、⌘U を押すか通知をクリックすると元に戻せます。

削除したノートは完全には消えず、ゴミ箱フォルダに残ります。「設定 → バックアップ → 削除したノートを復元…」から、どのノートでも新しいノートとして復元できます。

検索とコマンド

2 つのパネルは同じキーで操作します。入力して絞り込み、↑ ↓ で選択、Return で開き、Esc で閉じます。

ノートを検索 ⌘⇧F

  • 現在のすべてのノートの本文を検索し、ノートごとに 1 件表示します。
  • 入力欄が空なら全ノートを一覧するので、目次として使えます。
  • バックアップとゴミ箱は検索しません。

コマンドパレット ⌘⇧P

format で検索して「ノートを整形」を選ぶと、現在のノートの数式の空白と、JavaScript、TypeScript、JSON、HTML、CSS、Markdown、YAML のコードブロックを整形できます。コードにはインデント設定が適用され、操作全体を一度で取り消せます。

設定ウインドウを開かずに、ノートの操作や設定の変更ができます。

  • › の付いたコマンドは、アクセントカラーや言語などの 2 段目の一覧を開きます。現在の値には ✓ が付きます。
  • 不透明度、ぼかし、自動バックアップは数値を直接入力することもできます（例：75）。
  • Esc、または空の入力欄で ⌫ を押すと 1 段戻ります。前に選んでいた行は選択されたままです。
  • 1 段目で入力すると 2 段目の項目も見つかります。たとえば english と入力すると「言語：English」が表示されます。

同じショートカットをもう一度押すとパネルを閉じ、もう一方のショートカットを押すとパネルを切り替えます。

書く

ノートは普通の Markdown です。見出し、リスト、強調、リンクは入力しながらスタイルが付き、ファイルはどのエディタで開いても読みやすいままです。

  • チェックボックス：- [ ] と - [x] はクリックでチェックできます。
  • コメント：// で始まる行はコメントです。⌘/ で現在の行または選択した行のコメントを切り替えます。
  • コードフェンス：```js のようなコードフェンスは言語ごとに色分けされます。

長いノートでカーソルを動かすと、カーソルの上下に常に 3 行が見えるようにスクロールします。

スニペット

@ と単語を入力すると値を挿入できます。

  • Return で最初の形式を挿入、↑ ↓ で別の形式を選択、Esc で一覧を閉じます。
  • 複数の形式がある単語はすべて表示されます：@date ならすべての日付形式。
  • 単語の途中まで、または文字を順に入力しても見つかります：@wk で @week。
  • @ だけなら単語ごとに 1 行です。
  • プレビューは挿入される内容そのもので、時刻の値は常に最新です。

自分のスニペット

「設定 → スニペット」またはコマンドパレットの「スニペットを管理」で追加します。ノートのフォルダの snippets.json に保存され、ノートと一緒に移動・バックアップされます。

  • 1 つのトリガーに複数の行：macOS のユーザ辞書と同じです。住所をいくつか addr に登録すると、@addr ですべて一覧され、既定では最初の行が挿入されます。
  • 組み込みの単語と同じ名前：自分の行が先頭に入るので、自分の date が既定になります。
  • 内容は複数行にできます。

機能ブロック

機能ブロックは、ノートの一部をチェックリスト、計算機、合計、コードなどの小さなツールに変えます。1 つのノートにいくつでも置けます。

ブロックの追加と変更

  1. 空の行で / を入力します。（Vim モードでは先に挿入モードに入ります。）
  2. 矢印キーと Return、またはクリックでブロックを選びます。
  3. ブロックから出るには、最後の空行でもう一度 Return を押します。
  • ブロックのヘッダーか ⌘K：種類の変更、通常のテキストへの変換、削除。
  • ⌘⇧D：現在のブロックを削除。
  • ⌘O / ⌘⇧O：現在の行またはブロックの下 / 上に空行を追加。

どれも取り消せます。

@ で関数・単位・通貨を挿入する

計算ブロックで @ を入力すると、通常のスニペットに加えて 3 つの単語が表示されます。これらは計算ブロックの中でだけ表示されます。

単語一覧
@fnすべての関数と説明。sqrt() を挿入するとカーソルが括弧の中に入ります。引数を書いたら Tab で括弧の後ろへ移動できます。
@unit上の表の単位と、その種類。
@curすべての通貨と名前、表示言語の通貨に対するレート（日本語は JPY、英語は USD、簡体字中国語は CNY、繁体字中国語は HKD）。

  • 数値の直後に @ を書けます：10@km。
  • 既存のスニペットと重なる名前はそちらが優先です：分は @minute（@min は関数）、ミリ秒は @millisecond（@ms はタイムスタンプ）。

制限

  • 式は最大 256 文字です。
  • 剰余、行列、文字列、比較、独自の関数、式の中での = による代入には対応していません。

コード

  • ノート全体のコード：1 行目を code js にすると、ノート全体をその言語で表示・編集します。⌘L は 1 行目の言語を変更します。
  • ⌘L で現在のコードブロックの言語を選びます。
  • 括弧と引用符は自動で閉じられます。Return はインデントを保ち、Tab でインデント、⇧Tab でインデント解除します。
  • 何も選択していないときは、⌘C でブロック全体をコピーします。

インデント（スペース 2 つ、スペース 4 つ、タブ）と 3 種類の配色は「設定 → 編集」にあり、プレビューで確認できます。

Vim モード

Vim キーは最初からオンです。エディタはノーマルモードで始まり、i で入力を始め、Esc でノーマルモードに戻ります。ノーマルモードで Esc を押すとウインドウが隠れます。

  • ノーマルモードでは、コマンドが効くように一時的に英字（ASCII）入力に切り替わります。入力を始めるかウインドウを離れると、元の入力方式に戻ります。
  • 変換候補が開いているときは、Esc でまず候補を取り消してから挿入モードを終了します。
  • 取り消し履歴はノートごとに、アプリを終了するまで保持されます。

これはエディタ内の Vim エミュレーションで、Neovim ではありません。vimrc は読み込まれません。

「設定 → 編集 → Vim モード」またはコマンドパレットでオフにできます。オフにすると直接入力でき、Esc でウインドウが隠れ、⌘Z / ⌘⇧Z で取り消しとやり直しができます。

%SHORTCUTS%

データ

すべてのデータは Mac の中だけに保存されます。各ノートは UTF-8 の Markdown ファイルです。

~/Documents/Inkflit/
  notes/       ノートごとに 1 つの .md ファイル
  index.json   ノートの順番と選択中のノート
  backups/     以前のバージョン
  trash/       削除したノート

保存

  • 入力を止めて 0.5 秒後に保存します。入力中も少なくとも 2 秒ごとに保存します。
  • ノートの切り替え、ウインドウを隠す、アプリの終了ではすぐに保存します。
  • 保存に失敗するとフッターに表示され、保存に成功するまで終了できません。

バックアップと復元

  • 編集中、各ノートの以前のバージョンを最大 5 分に 1 回保存します。保持する数は「設定 → バックアップ」で選べます。
  • 「以前のバージョンを復元…」と「削除したノートを復元…」は新しいノートを作成し、元のファイルはそのまま残します。
  • index.json が壊れた場合は、「インデックスを再構築…」でノートファイルから作り直せます。古いインデックスは残ります。

保存場所を変更すると、保存フォルダ全体を新しい場所にコピーし、元のフォルダは残します。

Inkflit にはクラウド同期がありません。ノートのフォルダをご自身のバックアップに含めるか、同期サービスが対象にしているフォルダを選んでください。

自動化

ほかのアプリや AI エージェントは、ローカルの MCP サーバーまたは inkflit:// リンクでノートを読み書きできます。どちらも起動中の Inkflit を経由するので、保存とバックアップは通常どおり行われます。

MCP

MCP クライアントに Inkflit を追加し、クライアントを再起動します。

# Codex
codex mcp add inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# Claude Code
claude mcp add --transport stdio --scope user inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# そのほかのクライアント
{"mcpServers":{"inkflit":{"command":"/Applications/Inkflit.app/Contents/MacOS/Inkflit","args":["--mcp"]}}}

ツール：list_notes、search_notes、get_note、create_note、append_note、replace_note、delete_note。

  • ノートは index（Inkflit に表示される番号）か、変わらない id で指定します。ノートを追加・削除すると番号は変わります。
  • 新しいノートは末尾に追加されます。position に "first"、"last"、または数値を指定すると別の位置に置けます。
  • 削除したノートはゴミ箱に入ります。

リンク

open 'inkflit://note/append?index=2&content=Remember%20milk'
open 'inkflit://note/search?query=milk'
open 'inkflit://note/get?index=1'

操作は list、get、search、create、append、replace、delete です。x-success と x-error にコールバック URL を指定すると、結果を JSON で受け取れます。

書き込みや削除のリンクはすぐに実行されます。信頼できるリンクだけを開いてください。

トラブルシューティング

ショートカットが反応しない

ほかのアプリが同じショートカットを使っている可能性があります。その場合、メニューバーに「設定…（ショートカットを使用できません）」と表示されます。「設定 → 一般」で別のショートカットを選んでください。

ログイン時に起動がオンにならない

macOS の承認が必要な場合があります。「システム設定 → 一般 → ログイン項目」で Inkflit を許可してください。

Inkflit の外でノートが変更された

Inkflit の起動中にほかのアプリがノートファイルを変更すると、Inkflit は上書きを拒否します。現在の内容を安全な場所にコピーしてから、Inkflit を再起動してください。
