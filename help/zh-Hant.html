開始使用

Inkflit 常駐在選單列。按一個快捷鍵就能叫出來，記完隨手收起。輸入時自動儲存。

  1. 開啟視窗：按全域快捷鍵，預設為 ⌃⌥Space（可在「設定 → 一般」中變更），或點選單列圖示，選擇「開啟 Inkflit」。
  2. 開始寫：內容會自動儲存，沒有儲存按鈕。
  3. 收起視窗：再按一次快捷鍵，或按 Esc。切換到其他應用程式時也會自動收起。

視窗出現在哪裡

視窗會出現在滑鼠所在的顯示器、你目前所在的桌面上，不會把你拉回其他桌面。視窗位置會被記住，重新啟動後也一樣。

拖曳工具列中間的空白處可以移動視窗，拖曳邊緣可以調整大小。

引導筆記

第一次啟動時，Inkflit 會依你的語言建立四篇引導筆記，可以隨意修改或刪除。點設定視窗底部的「重新產生引導筆記」，會在最前面放一套新的引導，並開啟歡迎頁。

筆記

筆記像筆記本的書頁一樣排列：第一則是最早寫的，新增的筆記加在最後。工具列會顯示目前位置，例如 2 / 5。

  • 新增：⌘N，或工具列上的 +。
  • 翻頁：⌘[ 和 ⌘]，或工具列上的箭頭。
  • 跳到某一頁：⌘1 到 ⌘9 開啟第 1 到第 9 則。

底列顯示目前筆記的建立時間（本地時間）。在開始記錄建立時間之前就有的筆記不顯示日期。

刪除與復原

⌘D 直接刪除目前筆記。提示會保留 12 秒，按 ⌘U 或點擊提示就能找回。

刪除的筆記不會被真正抹除，而是放進回收站資料夾。在「設定 → 備份 → 還原已刪除筆記…」中可以把任何一則還原成新筆記。

搜尋與命令

兩個面板的按鍵一樣：輸入文字篩選，↑ ↓ 選擇，Return 開啟，Esc 關閉。

搜尋筆記 ⌘⇧F

在所有目前筆記的內文中尋找，每則筆記列出一筆符合結果。輸入框為空時會列出全部筆記，可以當目錄使用。備份和回收站裡的內容不會被搜尋。

命令面板 ⌘⇧P

不用開啟設定視窗，就能執行筆記操作、修改設定。

  • 帶 › 的命令會開啟第二層清單，例如介面主色、語言。目前生效的選項帶 ✓。
  • 不透明度、模糊和自動備份可以直接輸入數字，例如 75。
  • 按 Esc，或在空白輸入框裡按 ⌫，返回上一層，之前選取的項目仍然選取。
  • 在第一層直接輸入，也能搜尋到第二層的選項，例如輸入 english 會出現「語言：English」。

再按一次同一個快捷鍵關閉面板；按另一個快捷鍵則切換到另一個面板。

書寫

筆記就是一般的 Markdown。標題、清單、強調和連結會邊寫邊顯示樣式，原始檔用任何編輯器開啟都清楚易讀。

  • 核取方塊：- [ ] 和 - [x] 可以直接點擊勾選。
  • 註解：以 // 開頭的行是註解。⌘/ 為目前行或選取的行加上或取消註解。
  • 程式碼圍欄：```js 這樣的程式碼圍欄會依語言突顯。

在長筆記裡移動游標時，游標上下始終保留三行可見。

片段

輸入 @ 插入常用值。清單會預覽每個值，時間類的值即時更新；Return 或 Tab 插入，Esc 關閉清單。

片段插入內容
@date / @time日期，或精確到分鐘的時間
@timesec / @datetimesec含秒的時間，或含秒的日期和時間
@datetime精確到分鐘的日期和時間
@timestampUnix 時間戳記（秒）
@uuid隨機 UUID
@ip / @ipv4 / @ipv6公用位址，插入時才查詢
@localip這台 Mac 的區域網路位址
@mac該網路卡的 MAC 位址
@hostname / @computer主機名稱，或系統設定裡的電腦名稱
@whoami目前使用者名稱

公用位址在清單顯示或插入時向 ipify 查詢，不會傳送其他內容。在程式碼裡或緊接在字母後面時不會彈出，所以電子郵件地址不受影響。

功能區塊

功能區塊把筆記的一部分變成小工具：清單、計算機、加總或一段程式碼。一則筆記裡可以放任意多個功能區塊。

插入與修改功能區塊

  1. 在空行輸入 /。（Vim 模式下請先進入插入模式。）
  2. 用方向鍵和 Return 選擇，或直接點擊。
  3. 要離開功能區塊，在區塊的最後一個空行再按一次 Return。

用區塊的標題列或 ⌘K 變更類型、轉回一般文字或刪除。⌘⇧D 刪除目前區塊。這些操作都可以復原。⌘O 和 ⌘⇧O 在目前行或區塊的下方、上方插入一個空行。

功能區塊類型

功能區塊作用
清單每行一個核取方塊。點擊勾選，或在行尾輸入 /x。Tab 和 ⇧Tab 縮排和取消縮排，子項目會跟著父項目一起移動。
計算在行尾輸入 = 得出結果。支援百分比、函式、單位和變數，例如 price: 80。貨幣使用大寫代碼：10 USD to TWD =。
加總 / 平均值對區塊裡的數字加總或求平均，不計算運算式。
計數統計項目數、字數和字元數。
程式碼依語言突顯程式碼，見程式碼。

以 // 開頭的行不列入加總和計數。

匯率來自 Frankfurter。Inkflit 只下載公開匯率，不會上傳你的筆記。取得不到匯率時，功能區塊會直接提示，不會給出猜測的結果。

程式碼

  • ⌘L 選擇目前程式碼區塊的語言。
  • 括號和引號會自動補上。Return 保持縮排，Tab 縮排，⇧Tab 取消縮排。
  • 沒有選取內容時，⌘C 複製整個程式碼區塊。

縮排方式（2 個空格、4 個空格或 Tab）和三種配色在「設定 → 編輯」中，可以即時預覽。

Vim 模式

Vim 按鍵預設開啟。編輯器先處於一般模式，按 i 開始輸入，按 Esc 回到一般模式。在一般模式下按 Esc 會收起視窗。

  • 一般模式下，Inkflit 會暫時切換到英文（ASCII）輸入法，讓命令鍵直接生效；開始輸入或離開視窗時恢復你原本的輸入法。
  • 如果輸入法候選視窗還開著，按 Esc 會先取消候選，再離開插入模式。
  • 每則筆記的復原記錄會保留到結束應用程式為止。

這是編輯器裡的 Vim 模擬，不是 Neovim，不會讀取 vimrc。

在「設定 → 編輯 → Vim 模式」或命令面板裡可以關閉。關閉後直接輸入，Esc 收起視窗，⌘Z / ⌘⇧Z 復原和重做。

設定

按 ⌘, 或透過選單列圖示開啟設定。大部分選項在命令面板裡也能修改。

分頁選項

淺色和深色外觀跟隨 macOS。

資料

所有內容都只儲存在你的 Mac 上。每則筆記是一個 UTF-8 編碼的 Markdown 檔案：

~/Documents/Inkflit/
  notes/       每則筆記一個 .md 檔案
  index.json   筆記順序和目前選取的筆記
  backups/     歷史版本
  trash/       已刪除的筆記

儲存

停止輸入半秒後儲存，連續輸入時至少每兩秒儲存一次。切換筆記、收起視窗或結束應用程式時會立即儲存。儲存失敗時底列會提示，並且在儲存成功之前無法結束應用程式。

備份與還原

  • 編輯時，每則筆記最多每五分鐘保留一個舊版本。保留幾個可以在「設定 → 備份」中選擇。
  • 「還原歷史版本…」和「還原已刪除筆記…」都會新增一則筆記，原檔案保留不動。
  • 如果 index.json 損壞，「重建索引…」會依筆記檔案重新產生索引，舊索引會保留。

變更儲存位置時，會把整個儲存目錄複製過去，原目錄保留不動。

Inkflit 沒有雲端同步。請把筆記資料夾納入你自己的備份，或選擇一個同步服務已經涵蓋的資料夾。

自動化

其他應用程式和 AI 助理可以透過本機 MCP 服務或 inkflit:// 連結讀寫筆記。兩種方式都經過正在執行的 Inkflit，儲存和備份照常進行。

MCP

把 Inkflit 加入你的 MCP 用戶端，然後重新啟動用戶端：

# Codex
codex mcp add inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# Claude Code
claude mcp add --transport stdio --scope user inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

# 其他用戶端
{"mcpServers":{"inkflit":{"command":"/Applications/Inkflit.app/Contents/MacOS/Inkflit","args":["--mcp"]}}}

工具：list_notes、search_notes、get_note、create_note、append_note、replace_note、delete_note。

  • 用 index（Inkflit 裡顯示的序號）或穩定的 id 指定筆記。增刪筆記後序號會變動。
  • 新筆記預設加在最後。position 可以設為 "first"、"last" 或一個數字，放到其他位置。
  • 刪除的筆記進入回收站。

連結

open 'inkflit://note/append?index=2&content=Remember%20milk'
open 'inkflit://note/search?query=milk'
open 'inkflit://note/get?index=1'

可用的操作有 list、get、search、create、append、replace 和 delete。加上 x-success 和 x-error 回呼網址，可以收到 JSON 格式的結果。

寫入和刪除類的連結會立即執行，只開啟你信任的連結。

疑難排解

按快捷鍵沒有反應

可能有其他應用程式佔用了這個快捷鍵。這時選單列裡會顯示「設定…（快捷鍵無法使用）」，請在「設定 → 一般」中換一個快捷鍵。

登入時啟動無法開啟

macOS 可能需要你授權。請在「系統設定 → 一般 → 登入項目」中允許 Inkflit。

筆記在 Inkflit 之外被修改

如果 Inkflit 執行時筆記檔案被其他應用程式改過，Inkflit 會拒絕覆寫這些檔案。請先把目前內容複製到安全的地方，然後重新啟動 Inkflit。
