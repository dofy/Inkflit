Inkflit

Inkflit 是本地優先的 macOS 浮動筆記，支援多則筆記、Markdown、Vim 編輯、程式碼突顯、功能區塊與自動儲存。

建置與執行

需要 macOS 13 以上、Xcode Command Line Tools、Node.js 與 npm。

npm cinpm run buildopen build/Inkflit.app

npm test 測試編輯邏輯；npm run test:native 使用獨立筆記測試原生視窗、程式碼編輯與 Vim 復原。預設使用臨時簽章，可透過 QUICKNOTE_CODESIGN_IDENTITY 指定 Apple 開發者憑證；目前未經公證。

應用程式常駐選單列，按 Control + Option + Space 顯示或收起筆記，切換至其他應用程式時自動收起。拖曳視窗頂部或工具列中央空白處可移動視窗。預設寬高比為 2:3，可自由調整大小。選單列或 ⌘, 可開啟設定，調整快捷鍵、登入時啟動、儲存位置、主色、不透明度、背景模糊、程式碼配色與縮排；介面自動配合 macOS 淺色／深色模式。語言預設跟隨系統，也可選英語、簡體中文、繁體中文或日語。設定內附離線使用說明。

快捷鍵

快捷鍵 — 功能

⌘N — 新增筆記

⌘[ / ⌘] — 上一則／下一則筆記

⌘1 — 最新筆記

⌘D — 確認後刪除筆記，無法復原

⌘⇧D — 刪除目前功能區塊；可用 Vim u 復原

⌘K — 切換目前區塊類型

⌘L — 選擇程式碼區塊語言

⌘O / ⌘⇧O — 在目前功能區塊下方／上方新增可編輯的文字行

⌘/ — 切換目前或選取行的註解

Esc — 退出 Vim 編輯模式；普通模式再按一次收起視窗

Vim 由 CodeMirror 和 @replit/codemirror-vim 提供，並非 Neovim，也不讀取 vimrc。每則筆記的復原歷史僅在執行期間保留。普通模式會暫時切換英文鍵盤，插入模式或視窗失焦時恢復原輸入法；輸入法候選未確認時，Esc 先取消候選。

功能區塊

在插入模式的空行輸入 /，以方向鍵、Return 或滑鼠選擇。每則筆記可包含多個獨立區塊；點擊區塊標題或按 ⌘K 可切換類型、轉為純文字或刪除，這些操作可以復原。在非程式碼區塊的最後空行再按 Return 可離開區塊。

• list：點擊或在行末輸入 /x 勾選，結果儲存為 Markdown [x]。

• math：算式以 = 結尾，支援運算、百分比、函數、單位換算與區塊內變數，例如 price: 80。貨幣換算使用大寫代碼，例如 10 USD to CNY =。

• sum / avg / count：加總、平均，或統計非空項目、詞與字元；忽略 // 註解行。

• code：選擇語言突顯程式碼；設定中有三種配色及預覽，可選 2 空格、4 空格或 Tab 縮排。括號與引號自動配對，Return 自動縮排，Tab 縮排、Shift-Tab 減少縮排。無選區時 ⌘C 複製區塊內容。

• timer：timer 開始計時，timer 5、timer 3:30 開始倒數，timer pomo 啟動 25/5 分鐘番茄鐘。timer 5: 標題 設定標題；timer p、timer r、timer s 或按鈕可暫停、重設、停止。同時只能執行一個計時器；應用程式執行時結束會播放提示音並顯示可關閉的提醒，即使筆記視窗已收起。

區塊以 :::quicknote math、:::end 等 Inkflit 標記儲存在正文，不是程式碼圍欄；舊格式仍可讀取。匯率由 Frankfurter 提供，只取得公開匯率，不上傳筆記；服務無法使用時不會虛構匯率。

筆記與儲存

筆記預設儲存於 ~/Documents/Inkflit/notes.json，可在設定中指定資料夾。JSON 包含多則筆記，content 為帶有區塊標記的 Markdown。變更位置會複製筆記並保留原檔，不會覆蓋目標中已有的 notes.json；舊資料只在安全時複製。Inkflit 不提供雲端同步，但使用者選擇的資料夾可能由其他服務同步。建議定期備份。

Markdown 核取方塊（[ ]、[x]、- [ ]）可在編輯器點擊，原始內容仍為 Markdown。行首 // 為註解；標明語言的 Markdown 程式碼圍欄會突顯語法。
