Inkflit

Inkflit はローカル優先の macOS 用フローティングメモアプリです。複数のノート、Markdown、Vim 編集、コードの構文ハイライト、機能ブロック、自動保存に対応します。

ビルドと起動

macOS 13 以降、Xcode Command Line Tools、Node.js、npm が必要です。

npm cinpm run buildopen build/Inkflit.app

npm test は編集ロジックを、npm run test:native は独立したテスト用ノートでネイティブウインドウ、コード編集、Vim の取り消し・やり直しを検証します。標準では一時署名を使用します。QUICKNOTE_CODESIGN_IDENTITY で Apple 開発者証明書を指定できます。公証はされていません。

アプリはメニューバーに常駐します。Control + Option + Space で表示・非表示を切り替え、別のアプリに切り替えると自動的に隠れます。ウインドウ上端またはツールバー中央の空白部分をドラッグして移動できます。標準の幅:高さは 2:3 で、自由にサイズを変更できます。メニューバーまたは ⌘, から設定を開き、ショートカット、ログイン時の起動、保存場所、アクセントカラー、不透明度、背景のぼかし、コード配色、インデントを変更できます。外観は macOS のライト／ダークモードに追従します。表示言語は標準でシステムに従い、英語、簡体字中国語、繁体字中国語、日本語を選択できます。設定からオフラインヘルプを開けます。

ショートカット

キー — 操作

⌘N — 新規ノート

⌘[ / ⌘] — 前／次のノート

⌘1 — 最新のノート

⌘D — 確認後にノートを削除。元に戻せません

⌘⇧D — 現在の機能ブロックを削除。Vim の u で取り消せます

⌘K — 現在のブロックの種類を変更

⌘L — コードブロックの言語を選択

⌘/ — 現在行または選択行のコメントを切り替え

Esc — Vim の編集モードを終了。ノーマルモードでもう一度押すと隠れます

Vim は CodeMirror と @replit/codemirror-vim によるエミュレーションです。Neovim ではなく、vimrc は読み込みません。取り消し履歴は実行中のみノートごとに保持します。ノーマルモードでは一時的に英数字入力に切り替え、挿入モードやフォーカス喪失時に元の入力ソースに戻します。IME の変換候補がある場合、Esc は先に候補をキャンセルします。

機能ブロック

挿入モードの空行で / を入力し、矢印キーと Return、またはマウスで選択します。1 つのノートに複数の独立したブロックを置けます。ブロックの見出しまたは ⌘K から種類の変更、テキストへの変換、削除ができ、取り消しも可能です。コード以外のブロックの最後の空行で再度 Return を押すとブロックから出ます。

• list：クリックまたは行末の /x でチェックします。結果は Markdown の [x] で保存されます。

• math：式を = で終えると計算します。四則演算、パーセント、関数、単位変換、ブロック内の変数（price: 80 など）に対応。通貨変換は 10 USD to CNY = のように大文字の通貨コードを使います。

• sum / avg / count：数値の合計・平均、または空でない項目・単語・文字数を表示します。// のコメント行は除外します。

• code：言語を選択してハイライトします。設定では 3 種類の配色をプレビューでき、インデントはスペース 2 個、4 個、Tab から選べます。括弧と引用符を自動補完し、Return で自動インデント、Tab でインデント、Shift-Tab で解除します。選択範囲がない場合、⌘C はブロックの内容をコピーします。

• timer：timer でストップウォッチ、timer 5 や timer 3:30 でカウントダウン、timer pomo で 25/5 分のポモドーロを開始します。timer 5: タイトル で名前を指定。timer p、timer r、timer s またはボタンで一時停止、リセット、停止できます。同時に動作するタイマーは 1 つで、通知音にはアプリの起動が必要です。

ブロックは :::quicknote math、:::end などの Inkflit 独自マーカーとしてノート本文に保存され、コードフェンスではありません。旧形式も読み込めます。為替レートは Frankfurter から公開データのみを取得し、ノートは送信しません。取得できない場合にレートを捏造しません。

ノートの保存

標準では ~/Documents/Inkflit/notes.json に自動保存され、設定でフォルダを選択できます。JSON には複数のノートが入り、各 content は独自ブロックマーカーを含む Markdown です。保存場所の変更時はノートをコピーして元ファイルを保持し、移動先の既存 notes.json を上書きしません。旧データは安全な場合のみコピーします。Inkflit 自体にクラウド同期機能はありませんが、選択したフォルダが別のサービスで同期される場合があります。定期的なバックアップを推奨します。

Markdown のチェックボックス（[ ]、[x]、- [ ]）はエディタでクリックでき、元の形式は保持されます。行頭の // はコメントです。言語付きの Markdown コードフェンスもハイライトされます。
