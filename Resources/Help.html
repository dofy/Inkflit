Inkflit 使用帮助

随时记下一点想法。笔记自动保存在本机，支持 Markdown、Vim 和独立的功能块。

开始使用

默认按 ⌃⌥Space 唤起或收起笔记。切换到其他应用时浮窗会自动收起。点击菜单栏图标，或在 Inkflit 中按 ⌘, 打开设置，可更改全局快捷键和开机启动选项。设置窗口中按 ⌘W 关闭。

主窗口默认宽高比为 2:3，可以自由调整大小。“设置 → 外观”可选择界面主色、窗口不透明度和背景模糊强度；降低不透明度后可看到窗口后面的内容。代码高亮配色可在“设置 → 编辑”中选择和预览。

拖动窗口顶部或工具栏中央的空白区域可以移动窗口。界面会跟随 macOS 浅色或深色模式；“设置 → 语言”可选择英语、简体中文、繁体中文或日语，默认跟随系统语言。

唤起时，窗口出现在鼠标所在屏幕，并按窗口可移动范围（屏幕可用尺寸减去窗口尺寸）的百分比记住上下左右的相对位置，重启后也会恢复。调整不透明度或背景模糊时，按住 Option 可按 5% 一档吸附。

编辑与 Vim

Vim 默认开启，可在「设置 → 编辑」关闭；关闭后直接输入，Esc 收起窗口，⌘Z / ⌘⇧Z 撤销和重做。

普通模式下按 i 插入、u 撤销、⌃R 重做。Esc 先退出插入等编辑模式，在普通模式下再按一次收起窗口。拼音候选未上屏时，Esc 会先取消候选。编辑器提供 Vim 模拟，不读取 vimrc；撤销历史在应用退出后不会保留。

正文支持 Markdown，例如标题、列表和 - [ ] 待办。点击复选框可以切换状态。普通笔记中行首的 // 表示注释；代码块按所选语言处理注释和高亮。

首次启动会按系统语言创建四篇引导笔记。设置中的“重新生成引导笔记”会使用当前应用语言，将引导放在已有笔记之前。

功能块

在 Vim 插入模式或关闭 Vim 后，在空行输入 / 打开菜单，用方向键和回车选择。每个块只处理自己的内容，一条笔记可以包含多个不同功能的块。点击块头或在块内按 ⌘K，可切换类型、转为普通文本或删除块。在非代码块的最后一个空行再按回车可以退出块。

  • 清单：逐行显示复选框；点击或在行末输入 /x 切换。Tab 缩进当前事项，⇧Tab 减少缩进，每级两个空格。第一条事项保持根级，最多比前一条深一级；调整父事项时子事项一起移动。
  • 计算：在表达式末尾输入 =；支持变量、百分比、常见单位和货币换算，例如 10 USD to CNY =。变量定义及后续算式中的引用会高亮。货币换算需要获取公开汇率，不发送笔记内容。
  • 求和、平均值、计数：求和与平均值只提取数字，不计算算式或转换单位；例如 2+3= 会统计两个数字。计数统计当前块内的内容。
  • 代码：在块头选择语言；“设置 → 编辑”中的“代码配色”可选择并预览高亮方案。编辑时自动配对括号和引号，回车自动缩进；Tab 插入缩进，⇧Tab 减少缩进。在设置中可以选择 2 个空格、4 个空格或 Tab。无选区时 ⌘C 复制整个代码块，有选区时复制选中的文本。

数据保存

笔记默认分别保存为 ~/Documents/Inkflit/notes/ 下的 Markdown 文件，索引保存顺序和选中状态。设置中可选择备份保留数量、关闭备份或无限保留，并恢复历史版本、回收站笔记或重建索引。每篇笔记编辑时最多每五分钟保存一次旧版本；调整数量不会立即删除旧版本。更改位置时会复制整个目录并保留原目录。Inkflit 不提供云同步，请定期将整个存储目录备份到其他位置。 连续输入停止约 0.5 秒后保存，持续输入时通常最多约 2 秒保存一次；切换笔记、收起窗口、更改保存位置或退出应用会立即保存。保存失败会显示错误并阻止退出；应用异常崩溃时可能丢失尚未保存的最近修改。

搜索与自动化

点击顶部搜索按钮、按 ⌘⇧F 或在菜单栏选择“搜索笔记”，可搜索全部当前笔记。方向键选择结果，回车打开，Esc 关闭；不搜索备份和回收站。

本机 MCP 通过 stdio 提供 list_notes、search_notes、get_note、create_note、append_note、replace_note 和 delete_note。Codex 可以运行：

codex mcp add inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp

新建笔记时，create_note 的可选 position 可设为 "first"、"last" 或从 1 开始的插入序号（最大为当前笔记数加 1）；默认 "first"。例如 {"content":"我的笔记","position":"last"} 在末尾新建。URL 新建也支持 position=last 或数字位置。

Claude Code 可运行 claude mcp add --transport stdio --scope user inkflit -- /Applications/Inkflit.app/Contents/MacOS/Inkflit --mcp。在 Namo 的连接设置中添加本地 MCP，填写相同的可执行文件及参数 ["--mcp"]，保存后测试。Namo 和 Inkflit 需在同一台 Mac 以同一用户运行；所有获准对话的成员都能调用这些工具。

配置后重启 MCP 客户端。其他 MCP 客户端可配置命令 /Applications/Inkflit.app/Contents/MacOS/Inkflit 和参数 --mcp。使用从 1 开始的 index 或稳定的 id 指定笔记；新增、删除后编号会变化。追加或覆盖不指定目标时新建，追加时需要的话自动补换行。单次写入最多 1,000,000 个 UTF-16 代码单元。删除进入回收站；请求通过应用保存并备份。

scheme 地址为 inkflit://note/<action>，操作为 list、get、search、create、append、replace、delete，参数为 URL 编码的 index 或 id、content、query。例如：

open 'inkflit://note/append?index=2&content=Remember%20milk'
open 'inkflit://note/search?query=milk'
open 'inkflit://note/get?index=1'

不提供回调时，读取打开笔记，列表和搜索打开搜索界面。可选的 x-success / x-error 支持 URL 编码的自定义 scheme 回调，result 参数包含 JSON；不接受 HTTP、HTTPS、file 或 Inkflit 回调，JSON 最大 48 KB。写入和删除会立即执行，请只打开可信链接。
